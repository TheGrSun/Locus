The server publishes `resources://guide`, `resources://examples`, `resources://info`, `resources://official-demos`, and `graphs://{graph_id}`.
Prompts: `basic_graphing_assistant(formula)`, `advanced_math_analysis(formula, analysis_focus)`, and `visualize_3d(formula)`.

Official live demos, API v1.12: [parabola](https://www.desmos.com/api/v1.12/docs/examples/parabola.html) and [3D](https://www.desmos.com/api/v1.12/docs/examples/3d.html).
The v1.11 3D example URL returns HTTP 404.

The original copied general-purpose tutorial has been replaced with maintained instructions for this project.
